## Mental Model (Quick Recall)

```awk
awk 'pattern { action }' file
```

<CardGroup cols={2}>
  <Card title="pattern" icon="filter">
    When to run the action
  </Card>
  <Card title="action" icon="play">
    What to do (default: `print $0`)

  <Card title="$1, $2 ... $NF" icon="table-columns">
    Individual fields
  </Card>
  <Card title="$0" icon="file-lines">
    Whole line
  </Card>

## Common One-Liners (Daily Use)

<Accordion title="Print field(s)">
```awk
awk '{ print $2 }' file
```
Extracts the second field from each line.
</Accordion>

<Accordion title="Prefix output">
```awk
awk '{ print "ll  "$2 }' /etc/fstab
```
Adds a prefix to field output for better readability.
</Accordion>

<Accordion title="Print mountpoints only">
```awk
df -h | awk 'NR>1 { print $NF }'
```
Skips the header line and prints the last field (mountpoint).
</Accordion>

<Accordion title="Skip comments + blank lines">
```awk
awk '!/^#/ && NF { print $0 }'
```
Filters out comments (lines starting with #) and blank lines.
</Accordion>

<Accordion title="Filter rows by value">
```awk
awk '$3 == "ext4"' /etc/fstab
```
Shows only lines where the third field equals "ext4".
</Accordion>

<Accordion title="Lines matching regex">
```awk
awk '/error/ { print }' /var/log/app.log
```
Prints lines containing the word "error".
</Accordion>

## Field Separators (FS)

<CodeGroup>
```awk Input delimiter (colon)
awk -F":" '{ print $1 }' /etc/passwd
```

```awk CSV parsing
awk -F"," '{ print $3 }' file.csv
```

```awk Regex delimiter
awk -F"[ ,:]" '{ print $1 }'
```
</CodeGroup>

<Tip>
Use `-F` to specify custom field separators. Multiple delimiters can be specified using regex patterns.
</Tip>

---

## Output Formatting (OFS)

<Accordion title="Change output separator">
```awk
awk 'BEGIN { OFS="," } { print $1, $2 }' file
```
Outputs fields separated by commas instead of spaces.
</Accordion>

<Accordion title="Pretty formatting with printf">
```awk
awk '{ printf "%-20s %s\n", $1, $2 }'
```
Left-aligns first field in 20-character column.
</Accordion>

## Arithmetic & Aggregation

<Steps>
  <Step title="Sum a column">
    ```awk
    awk '{ sum+=$2 } END { print sum }'
    ```
    Adds up all values in the second field.
  </Step>
  
  <Step title="Count lines">
    ```awk
    awk 'END { print NR }'
    ```
    Returns total number of lines processed.
  </Step>
</Steps>

<Note>
The `END` block executes after all input lines have been processed, making it perfect for aggregations.
</Note>

## Conditionals

<CodeGroup>
```awk Simple if
awk '{ if ($3 > 10) print $0 }'
```

```awk If/else
awk '{ if ($3>100) print "HIGH"; else print "LOW" }'
```
</CodeGroup>

## Key Built-in Variables

| Variable | Meaning |
|----------|----------|
| `$0` | entire line |
| `$1..$NF` | fields |
| `NF` | number of fields |
| `NR` | line number (global) |
| `FNR` | line number per file |
| `FS` | field separator |
| `OFS` | output field separator |
| `RS` | record separator |
| `ORS` | output record separator |

## Useful Practical Snippets

<Accordion title="Remove duplicate lines">
```awk
awk '!seen[$0]++' file
```
Keeps only the first occurrence of each unique line.
</Accordion>

<Accordion title="Extract column and transform">
```awk
awk '{ print toupper($1) }'
```
Converts first field to uppercase.
</Accordion>

<Accordion title="Replace text inline">
```awk
awk '{ gsub("old","new"); print }'
```
Replaces all occurrences of "old" with "new" in each line.
</Accordion>

<Accordion title="Print field indexes (debug)">
```awk
awk '{ for (i=1;i<=NF;i++) print i, $i }'
```
Shows field number and value for debugging.
</Accordion>

## Real Sysadmin Examples

<Warning>
Always test AWK commands on sample data before running on production logs or system files.
</Warning>

### Parse fstab quickly

```awk
awk '!/^#/ && NF { print $1, $2, $3 }' /etc/fstab
```

Skips comments and blank lines, shows device, mountpoint, and filesystem type.

### Extract blocked IPs from logs

```awk
awk '/DENIED/ { print $NF }' firewall.log
```

Finds all "DENIED" entries and prints the last field (typically the IP).

### Show failed SSH attempts

```awk
awk '/Failed password/ { print $(NF-3) }' /var/log/auth.log
```

Extracts IP addresses from failed SSH login attempts.
